EXPLORE THE PLAYER

Tools for your playback workflow

01 / PLAY

Multi-axis Funscript playback

Play video and synchronize supported script axes in one desktop workflow.

02 / AUDIO

Audio-driven vibration

Optional audio-derived vibration; disabled by default. When analysis is unavailable, playback falls back to script vibration. Suction remains script-controlled.

03 / RHYTHM

BPM from audio

Estimate tempo using up to the first ten minutes of audio. The BPM value is a reference, not an automatic script rewrite.

04 / SYNC

Write offset into script

Apply playback timing changes to script data, including axes, bookmarks and chapters.

05 / CREATE

Script generation tools

Work with Funscript and SamNPlayer's script workflows without switching between unrelated applications.

06 / PRIVACY

Local-first approach

Designed for desktop workflows with optional local AI features.

GOOD TO KNOW

Frequently asked questions

Is SamNPlayer free?

Yes. Free by design, with no subscription or license-key activation.

Is SamNPlayer open source?

No. SamNPlayer is proprietary, closed-source freeware. The public repository hosts project information and downloads, not the application source.

Where is the latest build?

Check the public releases page. If no build is listed, public distribution is not yet confirmed.

How can I help?

Test available builds and share clear bug reports and feature suggestions through the public issue tracker.
